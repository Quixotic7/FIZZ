Put FIZZ on your FM-1

FIZZ is a step sequencer for FM TONE, ChoralRoot's FM voice, running on the M-VAVE FM-1 itself: tracks, per-step locks, chance, conditions, ratchets and chords. Try it in the browser first if you like.

Beta, for testers. Installing replaces the FM-1's firmware (M-VAVE's, or whatever it runs now). You can go back: see Going back.

What you need

  • Chrome or Edge on a computer (Windows, macOS, Linux or ChromeOS). The page talks to the FM-1 over USB MIDI with SysEx; the browser asks once to allow MIDI: allow it.
  • Safari (and every browser on iPhone and iPad) has no Web MIDI: this page can't install from it. Firefox asks for a site-permission add-on first and is not tested here. Phones and tablets are not tested.
  • A USB data cable straight into the computer. No probe or Transporter is needed.
  • Close other apps and tabs that use the FM-1's MIDI (editors, another firmware's page, a DAW).

This browser has no Web MIDI, so it can't install. Open this page in Chrome or Edge on a computer.

Back up first

Installing can lose what the FM-1 has saved. What to do depends on what it runs now:

  • Another firmware built on fm1-base (ChoralRoot and others): use its own backup page or tool first. The first time FIZZ starts, it erases the FM-1's shared save area if it finds another firmware's data there and none of FIZZ's.
  • M-VAVE's stock firmware: this page can't back up its saved sounds. If there are any you want to keep, assume they will be lost.
  • FIZZ already: an update writes only the program and FIZZ's data, not the save area, so your projects and presets stay in place. But betas can change how FIZZ saves, and FIZZ has no backup of its own yet.so save a backup first: back up FIZZ (opens in a new tab) to a file on this computer (Chrome or Edge, the same cable). The same page puts it back later.

M-VAVE's own updater, M-UPGRADE (m-vave.com: Downloads, PC Software), can also put the stock firmware back.

    
To another firmware

    
Open that firmware's own install page with FIZZ running and install as usual: FIZZ answers the same update request as the stock firmware and every fm1-base firmware.

    
If the FM-1 doesn't start

    
After two failed starts the FM-1 waits in the chip's update mode. On a Mac, felucca-bsp's rescue puts the stock firmware back from there: recovering an FM-1 that won't start (opens in a new tab). Then install FIZZ again. Ask on Discord if you get stuck.

    
If the FM-1 starts but FIZZ won't, hold SAVE while you switch it on: FIZZ's safe mode starts it without its saves (switch off and on to leave it). Holding REC while you switch on puts the FM-1 in update mode instead: then press Install (or Install the stock firmware) here.

  


  

    
Feedback

    
Tell us what works and what doesn't on FIZZ's Discord (opens in a new tab). Say which version you run (Check my FM-1 tells you).

    
If FIZZ crashed

    
Don't switch the FM-1 off: connect it by USB and press the button. The crash record survives a restart, not switching off. Paste what appears in Discord, with what you were doing.
