# FIZZ clean-room DSP: what to compute (the implementer's only source)

You write NEW code from this specification. Do not open, read or search: FMToneSeq/core/voice/** (any file),
FMToneSeq/tools/cr_tables.py, FMToneSeq/tools/build/**, the Felucca repository, the ChoralRoot repository, SLOOP,
Melodee, or anything under scratchpad/prov/ other than this cleanroom/ folder. Everything you need is here.
Write your own comments, structure and names for internals; the public names below are an interface that existing
code calls, so keep them exactly.

General rules: C99, integer arithmetic only at run time, `int32_t` wraps two's complement where stated, `>>` on a
negative int32 is an arithmetic (floor) shift (the targets are clang/gcc on ARM and x86: rely on it). "trunc" =
C integer division (toward zero). Every function `static inline` in a header (the file is included by one or two
translation units). Licence header of every file you write:

## 1. `tools/gen_fz_tables.py` → `core/voice/quad/fz_tables.h`

A Python 3 generator (standard library only) that writes the header. Python double precision; `int()` truncates
toward zero; `round()` is Python's (half-to-even; there are no ties in these tables). FS = 44100, CTL = 32.

The header defines `#define FS 44100` and `#define CTL 32` (guarded with #ifndef is fine) and these tables
(`static const`, exact element types and sizes):

| name | type [size] | value of entry i |
|---|---|---|
| `SINE` | int16_t [1025] | round(32767 · sin(2π i / 1024)), i = 0..1024 |
| `LFO_INC` | uint32_t [128] | int(h · CTL / FS · 2^32), h = 0.05 · 800^(i/127) |
| `SVF_G` | uint16_t [128] | int(4096 · tan(π · fc / FS)), fc = 30 · (16000/30)^(i/127) |
| `LEVEL_Q12` | uint16_t [128] | entry 0 = 0; i ≥ 1: round(4096 · 10^(((i − 112)/2)/20)) |
| `TANH_Q15` | int16_t [257] | int(32767 · tanh(i / 128)) |
| `QE_GLRATE` | uint16_t [128] | max(1, L >> 14), L = max(1, int(2^24 · 32 / (ms · 44.1))), ms = 10000^(i/127) |

and a function `static inline uint32_t pitch_inc(uint32_t p)` for p in 0..2047 (p = 1/16 semitones, MIDI note n at
16 n) that returns EXACTLY inc(p) = int(440 · 2^((p/16 − 69)/12) / FS · 2^32) (≤ 0x7FFFFFFF for every p) for every
p in 0..2047, using at most 1 KB of table (design it yourself; e.g. a table of one octave and shifts works if you
check exactness for all 2048 values in the generator and fail loudly if any differs). Out-of-range p: clamp to 2047.

Self-checks the generator must perform and print: sha256 of the comma-joined decimal values (first 16 hex chars):
SINE df65cad28317001d, LFO_INC 172b7c9ab0f79921, SVF_G 0f3f634405f511cc, LEVEL_Q12 22813877c0508647,
TANH_Q15 d7820ad657098430; QE_GLRATE[0] = 743 and the whole list equal to
QE_GLRATE_EXPECT (given in cleanroom/glrate_expect.txt). Also verify the pitch_inc scheme for all 2048 values.
Mark the header "generated by tools/gen_fz_tables.py: do not edit".

## 2. `core/voice/quad/fz_dsp.h` (includes `fz_tables.h`)

Public interface (names kept: existing code calls them):

- `#define CTL_LOG2 5` and a compile-time check that (1 << CTL_LOG2) == CTL.
- `#define VOICE_FS 24000` (a full-scale voice's nominal output level).
- `int32_t clamp(int32_t v, int32_t lo, int32_t hi)`: lo if v < lo, hi if v > hi, else v.
- `int32_t mulq15(int32_t a, int32_t b)`: (a·b) >> 15 with an int32 product.
- `int32_t sine_i(uint32_t ph)` and `int32_t osc_sine(uint32_t ph)` (identical): linear interpolation in SINE:
  i = ph >> 22; a = SINE[i]; b = SINE[(i + 1) & 1023]; f = (ph >> 7) & 0x7FFF; result a + (((b − a)·f) >> 15).
- `int32_t osc_tri(uint32_t ph)`: s = (int32)(ph >> 15); s − 32768 if s < 65536, else 98303 − s.
- `int32_t softclip(int32_t x)`: odd function over TANH_Q15: a = |x|; i = a >> 8; if i ≥ 256 the magnitude is
  TANH_Q15[256], else TANH_Q15[i] + (((TANH_Q15[i+1] − TANH_Q15[i])·(a & 255)) >> 8); result has x's sign.
- `int32_t soft_knee(int32_t y, int32_t k)`: a = |y|; if a ≤ k return y; else magnitude k + (softclip((a − k)·2) >> 1),
  with y's sign.
- `typedef struct { int32_t a1, a2, a3; } tsvf_t;` and `void tsvf_coef_k(tsvf_t *c, int32_t cut, int32_t k)`:
  cut clamped to 0..32512 (127 << 8); i = cut >> 8; g = SVF_G[i]; if i < 127, g += ((SVF_G[i+1] − g)·(cut & 255)) >> 8;
  den = 4096 + ((g·(g + k)) >> 12); a1 = (int32)(33554432u / (uint32)den); a2 = (a1·g) >> 12; a3 = (a2·g) >> 12.
- `void fz_svf_coef_fine(int32_t cut, int32_t k, int32_t *a1, int32_t *a2, int32_t *a3, int32_t *f2)` (a finer variant):
  cut clamped to 0..32512; i = cut >> 8; g = SVF_G[i] << 8 (Q20); if i < 127, g += (SVF_G[i+1] − SVF_G[i])·(cut & 255);
  den = 4096 + (int32)(((int64)g·(g + ((int64)k << 8))) >> 28); a1 = (int32)((4096u << 13) / (uint32)den);
  A2 = ((int64)a1·g) >> 15 (int64); A3 = (A2·g) >> 20 (int64); a2 = (int32)(A2 >> 5); f2 = (int32)(A2 & 31);
  a3 = (int32)(A3 >> 5).
- `void fz_svf_tick(int32_t a1, int32_t a2, int32_t a3, int32_t f2, int32_t *s1, int32_t *s2, int32_t x,
  int32_t *v1, int32_t *v2)`: one sample of a trapezoidal state-variable filter with states s1, s2 (int32):
  v3 = x − s2; v1 = (a1·s1 + a2·v3 + ((f2·v3) >> 5) + 4096) >> 13;
  v2 = s2 + ((a2·s1 + a3·v3 + ((f2·s1) >> 5) + 4096) >> 13);
  then s1 = clamp(2·v1 − s1, −150000, 150000), s2 = clamp(2·v2 − s2, −150000, 150000). (int32 arithmetic
  throughout, evaluated in that order; with f2 = 0 the f2 terms are 0.) Outputs v1 (band), v2 (low).
- `typedef struct { int32_t acc, rem; } fz_dc_t;` and `int32_t fz_dc_step(fz_dc_t *s, int32_t x)`: a DC blocker
  with error feedback: e = x·64 − acc + rem; d = e >> 12 (floor); rem = e − d·4096; acc += d; return
  x − ((acc + 32) >> 6). State starts at 0.
- `uint32_t fz_isqrt(uint32_t v)`: floor(sqrt(v)) exactly, for every uint32 v.
- `uint32_t fz_master_of_pot(uint32_t k)`: (k·k) >> 8 (k is 0..1023).

## 4. `core/voice/quad/fz_voice.h`: envelope, glide, drive, mix, chorus (includes fz_dsp.h)

### 4.1 `int32_t fz_env_step(int32_t *lvl, uint8_t *stage, uint32_t *prog, int op, const uint32_t *tatk, const uint32_t *tdec, int32_t atk, int32_t dec, int32_t sus, int32_t rel, int32_t dly, int gate, int adsr, int amp, int32_t bpm, int32_t op_floor, uint32_t dly_k)`

One control tick of an envelope. lvl is Q24 (1.0 = 1 << 24); stage: 0 off, 1 delay, 2 attack, 3 decay/sustain,
4 release, 5 release held; prog: the delay's progress (uint32). tatk / tdec are tables of 128 uint32 (Q24).
op: 1 for an operator envelope (dB-linear attack), 0 otherwise; amp: 1 for the amplitude envelope (its decay 127
holds). In this order:
1. If adsr is set, gate is 0 and stage is 1, 2 or 3: stage becomes 4.
2. By stage:
   - 1: prog += (uint32)clamp(bpm, 20, 300) · dly_k (uint32 wrap); if prog ≥ ((uint32)(dly & 127) << 24), stage 2.
     lvl unchanged.
   - 2: if op: lvl = max(lvl, op_floor); lvl += (int32)(((int64)lvl · tatk[atk & 127]) >> 24). Else
     lvl += (int32)tatk[atk & 127]. Then if lvl ≥ 1 << 24: lvl = 1 << 24, stage 3.
   - 3: if amp and dec ≥ 127: nothing. Else lvl += (int32)(((int64)(sus − lvl) · tdec[dec & 127]) >> 24).
   - 4 or 5: if rel ≥ 127: stage 5, nothing else. Else stage 4; lvl −= (int32)(((int64)lvl · tdec[rel] + 0xFFFFFF)
     >> 24) (rel is 0..126 here); then if lvl < 4096: lvl = 0, stage 0.
   - any other stage (0): lvl = 0.
3. Return lvl >> 9 (Q15).

### 4.2 `int32_t fz_ahd_step(int32_t *lvl, uint8_t *stage, uint32_t *prog, const uint32_t *tatk, const uint32_t *tdec, int32_t atk, int32_t hold, int32_t dec, int gate)`

An attack–hold–decay amplitude envelope sharing the stage numbering above plus 6 (hold) and 7 (decay); lvl Q24.
1. Stage mapping first: if stage is 3 → stage 6 and prog = 0; if stage is 1 → stage 2 and prog = 0; else if stage
   is 4 or 5 → stage 7.
2. By stage:
   - 2: lvl += (int32)tatk[atk & 127]; if lvl ≥ 1 << 24: lvl = 1 << 24, stage 6, prog = 0.
   - 6: if hold ≥ 127: if gate is 0, stage 7. Else prog += tatk[hold & 127] (uint32); if prog ≥ 1 << 24, stage 7.
   - 7: if dec ≥ 127 nothing; else lvl −= (int32)(((int64)lvl · tdec[dec & 127] + 0xFFFFFF) >> 24); if lvl < 4096:
     lvl = 0, stage 0.
   - other: lvl = 0.
3. Return lvl >> 9.

### 4.3 Glide

- `int32_t fz_glide_time_step(int32_t from, int32_t to, int32_t t)`: t is 0..127; d = |to − from|; ticks = 1 + t·t/8
  (trunc); return d/ticks (trunc) if that is > 0, else 1.
- `int32_t fz_glide_move(int32_t cur, int32_t target, int32_t step)`: step < 1 counts as 1; return cur moved toward
  target by at most step (never past it).

### 4.4 Drive: `typedef struct { int32_t hp, lp1, lp2; } fz_drive_t;` and `void fz_drive(fz_drive_t *s, int drive, int32_t *b, int n)`

drive 0..127. If drive is 0: return at once (state and samples untouched). Else with g = 4096 + 2·drive²,
kt = 32000 − 95·drive, mk = 30000 − 120·drive, bias = 2400, b0 = softclip(bias), for each sample x = b[i]:
hp += (x − hp + 64) >> 7; x2 = clamp(x − hp, −230000, 230000); y = softclip((((x2 >> 2)·g) >> 10) + bias) − b0;
lp1 += mulq15(y − lp1, kt); lp2 += mulq15(lp1 − lp2, kt); b[i] = mulq15(lp2, mk).

### 4.5 Mix of one voice into the stereo pair and three sends

- `void fz_pan_gains(int32_t pan, int32_t *gl, int32_t *gr)`: pan −64..63; gl = 4096 − (pan > 0 ? 64·pan : 0);
  gr = 4096 + (pan < 0 ? 64·pan : 0).
- `int32_t fz_send_gain(int32_t v)`: v·258 (v 0..127, Q15 gain).
- `int32_t fz_send_xmax(const int32_t now[3], const int32_t was[3])`: m = now[0] > was[0] ? now[0] : was[0];
  m = now[1] > m ? now[1] : (was[1] > m ? was[1] : m); m = now[2] > m ? now[2] : (was[2] > m ? was[2] : m);
  return 0x7FFFFFFF / (m | 1). (Exactly this sequence of comparisons.)
- `void fz_mix_voice(const int32_t *b, int32_t lvl, int32_t gl, int32_t gr, int32_t xmax, const int32_t was[3], const int32_t now[3], int32_t *l, int32_t *r, int32_t *s0, int32_t *s1, int32_t *s2)`
  for 32 samples (CTL): ramp steps dk = (now[k] − was[k]) >> 5; running gains gk start at was[k]. Per sample i:
  x = clamp(((clamp(b[i], −884000, 884000) >> 2)·lvl) >> 10, −524287, 524287); xs = clamp(x, −xmax, xmax);
  for k = 0, 1, 2 in order: gk += dk; if gk ≠ 0: sk[i] += (xs·gk) >> 15; then l[i] += (x·gl) >> 12;
  r[i] += (x·gr) >> 12. (int32 arithmetic.)

### 4.6 Chorus: two taps on one delay line

State: `int16_t line[2048]` (a ring), `uint32_t w` (write counter), `uint32_t ph` (LFO phase), and
`typedef struct { int32_t dc, oc, ra, rb; uint32_t live; } fz_chorus_t;`. Provide
`void fz_chorus_block(fz_chorus_t *c, int16_t *line, uint32_t *w, uint32_t *ph, const int32_t *in, int32_t *ml, int32_t *mr, uint32_t n, int32_t depth, int32_t rate, int32_t width)`
(depth, rate, width 0..127). Definitions: POS(p, d) = 102400 + (((sine_i(p) + 32768)·d) >> 12) (a delay in samples,
Q8); GLIDE(c, t) = c + ((t − c + (t > c ? 63 : 0)) >> 6). Steps:
1. dt = depth·96; ot = width·8454660; w0 = *w; p0 = *ph; p1 = p0 + (LFO_INC[rate & 127] / 32)·n (uint32);
   *ph = p1; *w = w0 + n (always, even if returning early).
2. If c->live is 0: if every in[i] is 0, return (nothing written, nothing added). Else c->dc = dt, c->oc = ot,
   c->ra = POS(p0, dt), c->rb = POS(p0 + (uint32)ot, dt).
3. If c->dc ≠ dt: c->dc = GLIDE(c->dc, dt). If c->oc ≠ ot: c->oc = GLIDE(c->oc, ot).
4. ea = POS(p1, c->dc); eb = POS(p1 + (uint32)c->oc, c->dc); da = ea − c->ra; db = eb − c->rb;
   RA = c->ra << 5; RB = c->rb << 5; c->ra = ea; c->rb = eb; if n ≠ 32: da = da·32/n, db = db·32/n (trunc, int32).
5. For i = 0..n−1 with the write position wi = w0 + i: x = in[i]; note whether x ≠ 0;
   line[wi & 2047] = (int16)clamp(x >> 1, −32768, 32767); then the left tap: RA += da; r = RA >> 5;
   k = wi − ((uint32)r >> 8); c0 = line[k & 2047]; c1 = line[(k − 1) & 2047];
   ml[i] += (c0 + (((c1 − c0)·(r & 255)) >> 8))·2; then the right tap the same with RB, db into mr[i].
6. c->live = 2048 if any input sample (this call) was nonzero; else c->live − n if c->live > n, else 0.
