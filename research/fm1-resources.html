Memory (RAM)

The FM-1 has about 458 KB of data memory in four regions, with no external RAM. Nearly all of it is in use, so any new feature has to take room from something else.

Inside FIZZ's app state (199 KB, the largest single block)

Flash (1 MB)

Flash holds the program, FIZZ's saved projects and sounds, and its fonts and ape drawings. The program area has room left; the save area is set by how many projects and sounds you can keep.

Processor time

Two cores at 360 MHz. Core 0 does everything today: the sound in a 5.8 ms window (256 samples at 44.1 kHz), and the screen and controls in whatever time is left. Core 1 sits idle until the dual-core build.

Audio, per 5.8 ms window (core 0)

white line = the deadline

One FM TONE voice (WOBBLE) takes about 364 µs per window, the same as ChoralRoot's engine, so 8 voices alone are about half the window. "Platform and mixing" is the block setup, the per-track mix and the output stage.

Screen and controls, per frame (core 0, between audio windows)

white line = 33 ms (30 fps)

Drawing depends on the screen: a held step redraws only the band that changes (about 3 ms), the idle bubbles redraw everything. Sending a full screen to the panel takes about 21 ms over SPI; a partial change takes less.
